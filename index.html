Passbook front page printing

For Epson passbook printers in Olivetti mode. Enter the details or read them from a slip, check the preview, then print.

1Upload slip

Photo or scan of an account form or slip (JPG or PNG). The account number, names, address and nomination are read and filled in. Always check them against the slip.

The slip stays on this computer. The reading tool is downloaded the first time, so an internet connection is needed. Works best on clear printed forms.

Kept only on this computer. The slip image is sent to Anthropic to be read, and your key is billed a small amount for each slip.

Text from the slip, or paste details

Reading a slip puts its text here so you can correct it. You can also type or paste one item per line and click Fill.

2Details to print

Labels such as "Account No:" are printed for you. Empty lines are left blank.

Customer

Branch details

Same for every customer of this branch. Saved on this computer.

3Preview and print

mm

Tap a line in the preview to select it, then move it by whole columns and lines.

Text sent to the printer

Raw text (to copy)

Printing tips
  • On the printer, use Olivetti (PR2) emulation, and set the condensed pitch and line spacing to the values under Layout.
  • In the Windows app, Print to printer sends the text straight to the printer. Elsewhere, save the text file and send it to the printer as plain text.
  • Test on plain paper first. Print ruler test prints column and line numbers so you can see where the text lands, then correct it with "Blank lines at top" and "Blank columns at left".
  • Hindi letters cannot be printed in text mode. They show as "?".

Printer grid

Every line is placed on the printer's character grid using spaces and line breaks only. Match these to the printer's own menu settings.


Line positions

Pick a line, then set its column and line number. Column 0 and line 0 are the top-left of the page.

Save your layout

Your layout and branch details are remembered on this computer. Customer details are never stored.

Prepare, preview and print the first page of a passbook, in standard mode or as text for a passbook printer in Olivetti mode.

Photo or scan of an account form or slip (JPG or PNG). The account number, names, address and nomination are read and filled in for you.

Printing tips
  • Standard: choose the paper size shown above (or the passbook size), scale 100% or "Actual size", margins none, headers and footers off.
  • Olivetti text mode: on the printer, use Olivetti (PR2) emulation, set the condensed pitch and line spacing to the values under Layout, then insert the passbook.
  • Send the saved .txt file to the printer as plain text, with no page formatting. On Windows, either print it from Notepad through a "Generic / Text Only" printer on the Epson's port, or run copy /b passbook-print.txt LPT1 (or the shared printer path).
  • Always test on plain paper first with "Fill sample data", then adjust the offsets under Layout.
  • Hindi letters cannot be printed in text mode. They show as "?".

Page and printer

The page is the printed lower half of the open passbook, 179 mm wide. Positions were measured from a photo, so expect to nudge things by a millimetre or two after a test print.

Passbook printers use about 17 characters per inch (1.49 mm) and 6 lines per inch (4.23 mm). Character width only applies to the passbook printer look.

Olivetti text mode

Each line is placed on the printer's character grid using spaces and line breaks only. Match the pitch and line spacing to the printer's own menu settings.

Field positions

Pick a line, then type its position or use the arrows. Positions are in mm from the top-left corner of the page.

Background guide

Add a scan or photo of a blank passbook page, cropped to the page. It shows behind the fields to help you line things up and is never printed.

Save your layout

Your layout and branch details are remembered on this device. Customer details are never stored.
